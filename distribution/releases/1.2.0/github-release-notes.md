# ParkTrack 1.2.0

This release makes the ParkTrack Android app faster and more reliable.

## What's new

- Added app settings, profile editing, dark theme, and full English localization.
- Improved parking availability and route loading, especially when moving quickly around the map.
- Improved in-app navigation performance, route matching, remaining-distance calculations, and ETA accuracy.
- Made authentication and expired-session recovery more reliable.

## Fixes and improvements

- Fixed accessible parking filtering.
- Prevented stale parking and routing responses from replacing newer results.
- Reduced unnecessary map redraws and cached parking markers, polygons, and clusters.
- Reduced false route recalculations caused by inaccurate GPS samples.
- Added an automated Google Play release workflow with localized release notes.
